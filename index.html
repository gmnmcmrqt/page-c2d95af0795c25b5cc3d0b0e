问：从获取订阅到建立连接，共分几步？

答：仅需三步标准操作，即可在本地客户端载入 稳联云 节点配置。

01

获取专属订阅链接

在稳联云控制台确认订购状态有效后，复制属于您账户的专属 API / 订阅配置地址，注意切勿泄露给第三方。

02

写入第三方客户端

打开本地兼容工具，新建订阅源并粘贴链接，执行同步更新。系统将自动拉取最新的节点地址列表及证书策略。

03

选择出站规则并联机

根据您的网络需求设定路由模式（如分流规则或全局模式），选中延迟与可用性匹配的线路节点，启用代理服务。

账户与计费相关

问：按月付和年付在权益上有何差别？

答：套餐所包含的节点范围、流量限额与设备上限完全一致，年付形式直接享受对应的折价优惠（相当于减免部分月费）。

问：设备数上限是如何计算的？

答：设备数是指同一时刻通过 稳联云 节点建立连接的独立终端数量。例如基础版允许 3 台设备同时活跃连接。

问：流量用尽后连接会中断吗？

答：当月配额耗尽后，节点中继将暂停转发请求，直到下一个账单周期重置，或通过控制台增购临时流量数据包。

连接与网络排查

问：提示“订阅更新失败”通常是什么原因？

答：请检查当前本地网络是否可正常解析域名，或者确认复制的订阅 URL 是否完整无空客字符。若持续异常，可在控制台重新生成令牌。

问：为什么某些网页仍显示未代理状态？

答：请核对客户端内部的分流策略。部分分流规则默认对大陆境内域名做直连放行，如需强制代理，需将该域加入自定义走代理名单或临时切换全局模式。

问：旗舰版的专线优化适合哪些场景？

答：旗舰版及以上提供的专线中继优先保障跨境低抖动与低丢包率，主要服务于跨服联机游戏以及高清流媒体的高码率缓冲。
